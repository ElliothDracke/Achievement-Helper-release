# Achievements Helper — releases

Les versions publiées d'**Achievements Helper**, un planificateur de succès pour Windows :
Journal de tes sessions, objectifs, overlay en jeu, bannière et son au déblocage.

- **Installer** : prends l'installeur `Achievements.Helper_<version>_x64-setup.exe` de la
  dernière release.
- **Mettre à jour** : rien à faire. L'application vérifie ce dépôt au démarrage
  (`latest.json`) et propose la nouvelle version ; chaque installeur est signé, la
  signature est vérifiée avant l'installation.

Le code source n'est pas ici : ce dépôt ne sert qu'à distribuer les versions.
